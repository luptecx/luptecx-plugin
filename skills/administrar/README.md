# Administrar

La operación de la empresa: plata, comunicación con los clientes y portafolio.

| Skill | Qué produce siempre igual | Usa | Estado | Prioridad |
|---|---|---|---|---|
| `luptecx-comunicacion-cliente` | Voz de LUPTECX y mensajes tipo: avance, incidente, mantenimiento programado, cobro. Las demás skills la usan para todo lo que sale hacia el cliente | — | Pendiente | 2 |
| `luptecx-cierre-mensual` | Concilia pagos de clientes y gastos, llena el Cierre Mensual en Notion y calcula la transferencia entre socios | — | Pendiente | 3 |
| `luptecx-caso-portafolio` | Al cerrar un proyecto: README, ficha del Portafolio y publicación para LinkedIn | `luptecx-estilo-visual` | Pendiente | 3 |

Al crear una skill de esta lista: carpeta `skills/administrar/<nombre>/SKILL.md`,
siguiendo `luptecx:escribir-skills`, y se actualiza esta tabla.
