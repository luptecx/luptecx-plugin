# Externas

Skills de terceros copiadas **tal cual** desde su repositorio, fijadas al commit de
`../../externas.json`. No se editan a mano: se traen y se actualizan con
`python herramientas/traer_externas.py` (desde `plugins/luptecx`), que también deja su
licencia en `licencias/`. Las que son plugins completos (Trail of Bits) no están aquí: son
dependencias del plugin, en el marketplace.
